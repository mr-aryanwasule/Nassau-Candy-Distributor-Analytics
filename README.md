# Nassau Candy Distributor Analytics

## Project Overview
This project analyzes the Nassau Candy Distributor dataset using **Python**, **Machine Learning**, and **Power BI** to generate business insights.

## Features
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Feature Engineering
- Machine Learning Pipeline
- Recommendation System
- Interactive Power BI Dashboards

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Joblib
- Power BI

## How to Run
1. Install dependencies:
   pip install -r requirements.txt
2. Run the Python modules.
3. Open the Power BI (.pbix) dashboard.
